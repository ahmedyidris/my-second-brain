### MCP Integration Code

**Python — Brain MCP Client:**
```python
import json
import subprocess

def query_obsidian(query):
    """Query Obsidian via brain-mcp"""
    result = subprocess.run(
        ["python", "brain_cli.py", "search", query],
        capture_output=True,
        text=True
    )
    return json.loads(result.stdout)

def create_note(title, content):
    """Create a note in Obsidian"""
    subprocess.run(
        ["python", "brain_cli.py", "create", title, content]
    )
```

**Python — NotebookLM Client:**
```python
from notebooklm import NotebookLM

def research_topic(topic, sources):
    notebook = NotebookLM.create(topic)
    for source in sources:
        notebook.add_source(source)
    return notebook.query(f"Summarize key findings about {topic}")
```
