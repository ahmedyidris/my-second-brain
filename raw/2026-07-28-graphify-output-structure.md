# Graphify — Output Structure

```
graphify-out/
├── graph.html       open in any browser — click nodes, filter, search
├── GRAPH_REPORT.md  the highlights: key concepts, surprising connections, suggested questions
└── graph.json       the full graph — query it anytime without re-reading your files
```

## What each file is

- **graph.html** — interactive force-directed graph; click nodes, filter by community, search concepts
- **GRAPH_REPORT.md** — curated highlights: god nodes, surprising cross-file connections, suggested queries
- **graph.json** — full graph data; used by `graphify query`, `graphify path`, `graphify explain` — no re-parse needed
