## HIGH

### 1. [contradiction/stale-claim] `claude-flow` treated as a separate entity from Ruflo
**Location:** `wiki/ruflo.md` ("Federation via claude-flow" section), `wiki/index.md` (Entities list), `wiki/agent-secure-comms.md` (frontmatter `related:`)
**Detail:** The vault described `claude-flow` as "a compatible project" sharing Ruflo's federation plugin ecosystem, with `[[claude-flow]]` listed as its own entity (broken wikilink — no page ever existed). Fresh research against `github.com/ruvnet/ruflo`'s own README found this is incorrect: **claude-flow is Ruflo's former name.** The creator (`rUv`) rebranded the project; the README states "Claude Flow is now Ruflo." Corroborated independently by a dev.to retrospective and a Medium quickstart guide (both found via web search, describing the same rename/rebuild timeline). Old package names (`@claude-flow/plugin-agent-federation`, `npx claude-flow@latest`) still work as legacy install paths during migration — that's why both command forms appeared in the sources.
**Fix applied:** Rewrote the section in `wiki/ruflo.md` to state the correct relationship (rename, not sibling project), with the correction explicitly flagged inline per the "never silently resolve contradictions" guardrail. Removed the `[[claude-flow]]` entity from `wiki/index.md` and from `wiki/agent-secure-comms.md`'s `related:` (replaced with `[[pal-mcp]]`, discussed in the same page). Did not create a `claude-flow` stub page — per the simplicity rule, correcting the existing page is better than adding an entity for something that isn't actually distinct.
**Sources:** github.com/ruvnet/ruflo README (primary); WebSearch aggregate of dev.to + Medium coverage (secondary, independent).

### 2. [missing-page] `PAL MCP` — referenced 2x, no page exists

**Fix applied:** Created `wiki/pal-mcp.md` from the project's GitHub README (primary source) plus a corroborating WebSearch aggregate (secondary). Linked from `the-council.md` and `agent-secure-comms.md`.

Same underlying issue as #1; listed separately because it was flagged first by the mechanical broken-link scan before the contradiction was discovered during research. No separate fix needed beyond #1.
