# Narmer

Narmer is the unified core of a local-first AI operating system. Named after the first Pharaoh who united Upper and Lower Egypt, it brings together fragmented local tools into one sovereign entity. It combines a 3B parameter coding model with kernel-level sandboxing (OpenShell), a hybrid SQLite memory brain, and a zero-trust public edge (Cloudflare Tunnel).
