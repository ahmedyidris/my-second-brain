# Self-Improvement Loop

The core innovation that makes [[jarvis-x]] a true agentic OS rather than a chatbot. [[hermes-agent]] analyzes its own daily activity logs and generates improvements.

## The loop

```
Daily Activity Log
        ↓
Meta-Agent Review (Hermes analyzes itself)
        ↓
Identifies: What worked? What failed? What's missing?
        ↓
Generates: Improved prompts, new tools, new skills
        ↓
Auto-Implements (with safety checks per [[constitutional-autonomy]])
        ↓
Logs the change → Repeat
```
