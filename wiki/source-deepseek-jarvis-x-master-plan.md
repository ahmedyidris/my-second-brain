## Later sources

[[source-jarvis-x-starnet-handoff]] (dated 2026-09-24) reports the as-built state of [[jarvis-x]]. It differs from this plan in several places. The full area-by-area comparison is in [[jarvis-x-plan-vs-reality]]. Examples, as of the 2026-09-24 handoff:

- **Body (Book II):** the plan has a Lenovo Y50-70 on Pop!_OS 24.04 LTS. The handoff has an ASUS Chromebook running Crostini (Debian 13 trixie), with an 11th Gen i5, no GPU and 14GB RAM ([[crostini]], [[jarvis-x-hardware]]).
- **Local models (Books II, III, IX):** the plan has `llama3.2:3b`, `qwen3:1.5b` and `hermes3:8b`. As built, Jarvis uses the Qwen 2.5 family, with `qwen2.5:3b` as the `local` tier. `nomic-embed-text` appears in both ([[ollama]]).
- **Voice (Book VI):** the plan has Faster-Whisper and Piper. As built, a `tts-worker` targets Chatterbox TTS, and it is degraded because the model isn't installed ([[jarvis-x-voice-engine]]).
- **Council (Book IV):** the handoff's multi-agent work is [[starnet]], plus a proposed [[jarvis-x-station-view]] (Priority 3) whose roster would be at `config/agents.yaml`. This plan's appendix file structure lists the same path (`jarvis-x/config/agents.yaml`).
- **Not covered by the handoff:** Book V (Memory), Book VII (Trade), Book VIII (Wealth) and Book X (Lore).

> **Disagreement (2026-09-24 handoff vs DeepSeek Jarvis X Master Plan):** Book II names the body as a Lenovo Y50-70 on Pop!_OS 24.04 LTS. The handoff's machine is an ASUS Chromebook running Crostini (Debian 13 trixie). The handoff doesn't say whether the Y50-70 was retired or is still the target.

> **Resolved by the human (2026-09-25):** the Chromebook is the current machine ("Current machine is chrome boo[k]"). See [[jarvis-x-hardware]].
